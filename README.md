# progresso-estudos-python

Repositório para registrar meu progresso nos estudos de Python, com o objetivo
de trabalhar com AI Engineering.

## Estrutura

```
estudos/
├── 01-python-basics/
│   ├── 01-functions/        # funções e lógica básica
│   ├── 02-dictionaries/     # dicionários (chave/valor, loops, checagens)
│   └── 03-mini-finance/     # mini sistema de finanças pessoais
│
├── 02-python-modules-and-apis/
│   ├── 01-modules/          # import de módulos (calculadora + modules)

│
```

## Trilha

1. **Python básico** — funções, dicionários e um mini projeto financeiro.
2. **Módulos e APIs** — organização em módulos e requisições HTTP.
3. **Fundamentos de LLM** — tokenização, embeddings e geração de tokens.
4. **LLM na prática** — construção de um chat com histórico via API.
